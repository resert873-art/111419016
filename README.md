# 林予白｜个人设计师作品集首页

纯 HTML + CSS 制作，布局参考用户提供的截图。

## 本地预览
用浏览器打开 `index.html`。

## 发布到 GitHub Pages
上传 `index.html`、`style.css` 到 GitHub 仓库根目录，再进入 Settings → Pages，选择 `Deploy from a branch`、`main`、`/(root)` 并保存。

## 主视觉
目前用 CSS 形状模拟打开的书、红色圆形、枝条与石头。如需更贴近参考图，建议将真实照片放到 `images` 文件夹，并替换 `.feature-image` 的 CSS 造型。
